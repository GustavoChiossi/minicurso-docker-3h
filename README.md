# Minicurso Docker

Material prático para introdução ao Docker, dividido em dois roteiros.

## Roteiros

### 1. Dockerfile

Roteiro prático sobre a criação de imagens Docker utilizando um `Dockerfile`.

Aborda a construção de uma imagem, configuração do ambiente e execução de uma aplicação em um container.

Diretório: [`dockerfile/`](./dockerfile)

### 2. Docker Compose

Roteiro prático sobre o uso do Docker Compose para definir e executar aplicações compostas por múltiplos containers.

Aborda a configuração dos serviços e sua execução utilizando um arquivo `compose.yaml`.

Diretório: [`compose/`](./compose)

## Requisitos

* Docker
* Docker Compose

Os roteiros podem ser executados localmente utilizando o Docker instalado na máquina.
